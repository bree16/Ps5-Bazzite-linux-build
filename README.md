# PS5 Bazzite Linux Gaming & Windows Compatibility Lab

Documentation of booting **Bazzite KDE Linux** on an original PlayStation 5 from external storage, running Windows games through **Steam Play / Proton**, and testing an unofficial community **Aurora** launcher workflow.

## Tested environment

Original PS5 · firmware 11.60 · PS5 Bazzite Deck v2.7.3 · external 2 TB SSD · GE-Proton 12-11 · Elden Ring / Elden Ring Nightreign

## Skills demonstrated

Linux administration (Bazzite/Fedora atomic) · command-line troubleshooting · disk-image preparation and SHA-256 verification · Python environments and GUI dependencies · Wine/Proton compatibility troubleshooting · Git/GitHub documentation · reproducible technical writing

## Scope and safety

This repository contains documentation only. It does not distribute firmware, exploit files, payload binaries, game files, proprietary trainer files, or credentials. Trainer use is limited to offline single-player testing; nothing here bypasses anti-cheat. Results describe one tested setup and are not guaranteed for other firmware or releases.
